# cpp-array-sort
C++ console application that displays an unsorted array of strings and sorts them alphabetically using sort
## Overview
- Stores an array of 32 full names (formatted as `Last, First Middle`).
- Prints the original unsorted list to the console.
- Sorts the array alphabetically using standard string comparison.
- Outputs the cleanly sorted list.

## Requirements & Compilation
Requires a standard C++ compiler (such as `g++` or `clang++`).

```bash
g++ -std=c++17 main.cpp -o name_sorter
./name_sorter
